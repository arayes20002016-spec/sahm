# سَهم — SAHM Download Manager

مدير تنزيلات لـWindows x64 بواجهة عربية وإنجليزية، مكتوب بـJavaScript وElectron. كود المشروع متاح بموجب [GPL-3.0-or-later](LICENSE). الإصدار 0.25 تجريبي؛ لم يُثبت تكافؤ شامل مع IDM، ولم يُعلن إصدار مستقر بعد.

يضيف هذا الإصدار [اختيار صيغة الفيديو والمسار الصوتي](docs/MEDIA-OPTIONS.md) في التطبيق وزر الفيديو في المتصفح. تتوفر MP4 وMKV وWebM بحسب ترميزات المصدر، وMP3 وM4A للصوت فقط، مع الدقة وحجم معلن أو تقديري عند توفره. تُحفظ الاختيارات عند الإيقاف والاستئناف، وتستمر [إعادة الاتصال تلقائيًا](docs/NETWORK-RECOVERY.md) وفق سياسة الشبكة والقوائم والحصة. تظل النسخة تجريبية وفق [خطة القبول](docs/PRODUCT-READINESS.md).

تضيف الحزمة 0.24.0 [اختيار العربية والإنجليزية](docs/LANGUAGES.md)، واتجاه النص والحقول حسب لغة الواجهة، وأرقامًا لاتينية في الحالتين. يُختبر المثبّت الحقيقي في VM منفصلة عن اختبارات محتوى الحزمة؛ تُسجّل نتائج التثبيت والترقية والإزالة في أدلة الإصدار. لا تُعد نتيجة تثبيت ناجحة وحدها إعلانًا عن إصدار مستقر.

يدعم HTTP/HTTPS والاستئناف والتنزيل المجزأ وFTP/FTPS والقوائم والجدولة والحصص وقواعد الخوادم والوكلاء. تتكامل إضافة Chrome وEdge مع التطبيق لالتقاط التنزيلات وإظهار زر الفيديو. تتوفر تنزيلات YouTube العامة وHLS/DASH المسجلة غير المشفرة ضمن الحدود الموضحة أدناه. ينسخ المواقع إلى لقطات محلية، مع جلسات دخول معزولة ومزامنة دورية ومسارات SPA التي تستخدم hash.

يضيف 0.25 بيانات الإضافة باللغتين في مدير إضافات المتصفح، وحالة متجر مستقلة لكل متصفح، وإعدادًا اختياريًا يفتح صفحة المتجر عند توفرها. مسار النشر المجاني المختار هو Edge؛ تتوفر الخصوصية والدعم في هذا المستودع؛ لم يُجهز حساب ناشر Edge أو اعتماد متجر حتى الآن. تظل التجربة الحالية عبر وضع المطوّر.

## التشغيل من المصدر

المتطلبات: Windows x64، وNode.js 24.19.0 أو أحدث من سلسلة 24، وWindows PowerShell 5.1 و.NET Framework. تتطلب اختبارات TLS برنامج OpenSSL، مثل النسخة المرفقة مع Git for Windows.

~~~powershell
npm ci
npm run check
npm run media:setup
npm run media:verify
npm test
npm start
~~~

يحتاج تجهيز أدوات الفيديو أول مرة إلى الإنترنت. تُجلب الإصدارات والبصمات من media-runtime.lock.json؛ لا يُستبدل أي إصدار بآخر لمجرد أنه الأحدث. لا يلزم شراء خدمة لتشغيل المشروع أو بنائه.

## تكامل المتصفح

من «المتصفح» داخل سَهم سجّل الاتصال وافتح مجلد الإضافة. في chrome://extensions أو edge://extensions فعّل وضع المطوّر ثم «تحميل إضافة غير مضغوطة»، واختر ذلك المجلد. فعّل الالتقاط وزر الفيديو واترك سَهم يعمل.

عند تحديث إضافة محملة من مجلد إصدار قديم، أزلها وحمّل مجلد الإصدار الجديد ثم أعد تحميل صفحة الفيديو. تثبيت التطبيق وحده لا يستبدل إضافة محملة يدويًا من مسار آخر. لا توجد إضافة منشورة في المتاجر بعد.

جُهزت حزمة ZIP للنشر ومسارات فتح صفحة المتجر في Chrome وEdge. تحتاج إلى حساب ناشر ومراجعة المتجر ثم ضبط المعرف والرابط في browser/store-release.json وإعادة البناء. يشرح [دليل النشر](docs/EXTENSION-PUBLISHING.md) الخطوات وسياسة الخصوصية؛ لا تمنح هذه الملفات اعتمادًا من المتاجر.

## حدود النسخة

YouTube العام المسجل مدعوم؛ المحتوى الذي يحتاج تسجيل دخول والبث المباشر وDRM غير مدعوم. لا تُنقل Cookie إلى تنزيلات YouTube. يتاح اختيار الحاوية والدقة ومسار صوتي واحد بعد الفحص. الملفات المباشرة تحفظ بصيغتها الأصلية، ويمكن استخراج الصوت إلى MP3 أو M4A من روابط الوسائط المدعومة، بمسار صوتي واحد وفحص الملف النهائي.

نسخ الموقع يحفظ لقطة ثابتة ولا يشغّل قاعدة بيانات أو API الموقع دون اتصال. مصادقة NTLM وPFX داخل نافذة الموقع مقيدة بالأصل والمنفذ المضبوطين؛ حد جسم الطلب 4 MiB وحد المورد 32 MiB. Kerberos من KDC فعلي والبطاقات الذكية لم يُختبرا. يضاف مرفق POST بعد اكتماله في المتصفح دون إعادة الطلب أو نسخ الملف؛ استخدم المتصفح أثناء النقل، ولا تسري عليه حصة سَهم؛ راجع [سياسة الأمان](SECURITY.md).

التثبيت والتحديث يدويان. المثبت التجريبي غير موقّع. إغلاق النافذة يبقي التطبيق يعمل في شريط النظام؛ «خروج» ينهيه.

## البناء والمساهمة

~~~powershell
npm run pack
npm run smoke:packaged-site-routes
npm run installer
npm run verify:release
npm run source:archive
~~~

المخرجات تحت dist. يختبر verify:release محتوى المثبت دون تشغيله، ويقارن الملفات بالحزمة والمصدر والبصمات المقفلة. يُصدّر source:archive الشفرة والاختبارات وإعدادات البناء دون بيانات المستخدم أو عينات البرامج المملوكة.
