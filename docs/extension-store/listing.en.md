# SAHM — Browser Integration

Connect Chrome or Edge downloads to SAHM, a free, open-source Windows download manager. This companion extension requires the SAHM desktop app to be installed and running on the same computer. It does not download files on its own.

Send a link from its context menu or enable capture for direct downloads. The video button shows supported media and the video or audio options available from the source. Exclude websites or keep the next download in the browser.

Automatic capture starts off. Session downloads and completed POST attachments each require separate approval in both the app and extension. For POST attachments, the browser completes the original response and SAHM records the completed file without sending the request again. If SAHM is unavailable, the browser keeps the download.

The interface supports Arabic and English. There are no ads, paid subscriptions, or developer analytics. Download information is sent locally to SAHM through Native Messaging. With session capture enabled, SAHM may use the required session headers to download from the original source. Incognito browsing is not supported.

Download content you own or have permission to save. DRM-protected media and live streams are not supported. Compatibility with every website or player is not guaranteed.
