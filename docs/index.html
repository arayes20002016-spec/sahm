سَهم — مدير التنزيلات

تطبيق Windows مجاني ومفتوح المصدر بواجهة عربية وإنجليزية. يدعم تنزيل الملفات والاستئناف والقوائم والجدولة، ويتصل بالمتصفح عبر إضافة اختيارية.

الإصدار 0.25.0 تجريبي. المثبّت غير موقّع، والتحديث يدوي. إضافة المتصفح لم تُعتمد في المتاجر بعد؛ ما زال إعدادها التجريبي يحتاج وضع المطوّر.

تحميل النسخة التجريبية وقراءة نتائج الاختبار

SAHM Download Manager

A free, open-source Windows download manager with Arabic and English interfaces. It supports file downloads, resume, queues, and scheduling, with optional browser integration.

Version 0.25.0 is experimental. The installer is unsigned and updates are manual. The browser extension has not been approved by a store yet; trial setup still requires developer mode.
