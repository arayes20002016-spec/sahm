# ضغط التنزيل والتعافي

يشغّل `npm run test:stress` مدير التنزيل الحقيقي في عملية منفصلة، بملف مستخدم جديد وخادم HTTP محلي. المدة الافتراضية 1800 ثانية، مع أربع مهام نشطة وأربعة اتصالات لكل ملف يدعم Range. يتضمن كل فوج ثمانية ملفات بحجم 4 MiB: نقل عادي، وقطع اتصال بعد بيانات فعلية، واستجابتان مؤقتتان 503، وخادم لا يدعم Range. يفحص المشغّل SHA-256 والحجم لكل ملف مكتمل.

~~~powershell
npm run test:stress -- --duration-seconds 1800 --result-directory E:/SAHM-QA/stress-unique
~~~

يجب أن يكون مجلد النتائج جديدًا. لتشغيل كود الحزمة الموزعة، عيّن `--application-root` إلى المسار المطلق لـresources/app.asar و`--runtime` إلى SAHM.exe. يستخدم المشغّل وضع Node في الملف التنفيذي المشحون؛ لا يشغّل الواجهة الرئيسية أو المثبّت، ولا يفتح بيانات المستخدم الشخصية. تُختبر النوافذ وتكامل المتصفحات بفحوصهما المنفصلة.

ينفذ المشغّل أربع حالات على الأقل، حتى عند طلب مدة تطوير قصيرة. يحتفظ خادم الاختبار باستجابات جزئية قبل الإنهاء القسري أو الإغلاق المنظم. تُقرأ نقاط الاستئناف بعد توقف العملية، وتُقارن البايتات التي تعلنها بالأصل، ثم يُعاد فتح السجل نفسه ويُتحقق من بقاء معرّفات المهام دون فقد أو تكرار. بعد الاستئناف، يجب تسجيل طلبات Range تبدأ من إزاحات محفوظة غير صفرية. يبدأ التدفق الذي لا يدعم Range من جديد، وتبقى أجزاؤه السابقة محفوظة حتى تنظيف بيانات التجربة.

في حالة انقطاع الشبكة يقطع الخادم اتصالاته ويغلق الطلبات الجديدة لمدة ست ثوانٍ افتراضيًا. يمكن تغييرها بخيار `--outage-ms`. لا تتغير إعدادات شبكة الجهاز. يراقب الاختبار انتظار إعادة الاتصال ويشترط إكمال الملفات تلقائيًا دون أمر استئناف بعد عودة الشبكة؛ أي انتقال إلى خطأ يفشل الدورة. لا يعيد المشغّل الحالة كاملة لإخفاء فشلها. يتناوب الانقطاع مع الإيقاف والاستئناف، وتبقى العملية نفسها تعمل عبر أفواج كثيرة؛ الإنهاء القسري التالي عند الفوج الستين. يستخدم هذا الفحص بيانات تميّز موضع كل كتلة.

تُحفظ تفاصيل الطلبات والبصمات ونقاط الاستئناف في waves.jsonl، وعينات الذاكرة وCPU وتأخر حلقة الأحداث في samples.jsonl، والنتيجة في result.json. حد RSS الافتراضي للعملية 512 MiB؛ يمكن تغييره بخيار `--max-rss-mib`. أخذ العينات لا يثبت غياب كل تسرب ذاكرة، ولا يمثل قياس سرعة مقارنةً ببرنامج آخر.

لتقييد مساحة القرص، يحذف المشغّل الملفات التي أنشأها في الأفواج السابقة بعد فحصها وتسجيل بصماتها، ويحتفظ بآخر فوج. يتحقق من بقاء مسار كل ملف داخل مجلد تنزيلات التجربة قبل التنظيف. يظل سجل المهام محفوظًا لتغطية ازدياد حجمه أثناء التشغيل. لا ينظف المشغّل مجلدات تنزيل حقيقية أو إصدارات أخرى.

يبقى انقطاع طاقة Windows وامتلاء قرص فعلي وتثبيت NSIS وترقيته ضمن قبول منفصل. هذه الدورة تختبر إنهاء العملية وقطع اتصالات النقل، ولا تحاكي فقد مخازن القرص عند انقطاع الكهرباء.
