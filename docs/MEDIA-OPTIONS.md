# اختيار الفيديو والصوت

في سَهم 0.23 افتح «تنزيل جديد»، وأدخل رابط YouTube عام أو قائمة HLS/DASH مسجلة، ثم اختر «فحص الصيغ والمسارات الصوتية». تظهر الصيغ والدقات والصوت المتاح من المصدر. الزر فوق الفيديو في إضافة المتصفح يعرض الاختيارات نفسها بعد الفحص، ثم يرسلها إلى سَهم عند الضغط على «تنزيل باستخدام سَهم».

| الصيغة | الاختيار |
|---|---|
| تلقائي | يحافظ على سلوك التنزيل السابق وأفضل اختيار متاح. قد يختلف امتداد الملف بحسب المصدر والدمج. |
| MP4 | صورة H.264 وصوت AAC عند توفرهما، لتوافق أوسع مع المشغلات. |
| MKV | يجمع الترميزات المتاحة دون تحويلها. |
| WebM | صورة VP8/VP9/AV1 وصوت Opus/Vorbis المتوافقان، عند توفرهما. |
| MP3 | صوت فقط، بتحويل إلى MP3 بمعدل مستهدف 192 kb/s. |
| M4A | صوت AAC فقط؛ يُنسخ AAC دون تحويل، وتُحوّل الترميزات الأخرى إلى AAC بمعدل مستهدف 192 kb/s. |

يُحفظ مسار صوتي واحد. يميز الاختيار لغة المصدر وترميز الصوت ومعدل البت والقنوات حين يعلنها المصدر. قد توجد عدة صيغ للغة نفسها. يظهر «الصوت الافتراضي» أيضًا. إذا تغيرت الحاوية أو الدقة، تقتصر قائمة الصوت على الاختيارات المتوافقة؛ تتغير القيمة إلى الافتراضي إن لم يبق الاختيار السابق متاحًا.

يعتمد الحجم المعروض على حجم مسارات المصدر، أو على تقديره للحجم أو معدل البت والمدة. تُكتب كلمة «التقديري» عندما يُحسب تقدير، وقد يتغير الحجم بعد الدمج. عند غياب هذه المعلومات يظهر أن الحجم غير متاح. لا تُحمّل مقاطع الفيديو لمجرد عرض الخيارات.

يحفظ سَهم الاختيار مع المهمة، ويفحصه مجددًا قبل التنزيل. إذا اختفى المسار أو تغيرت هوية الصيغة، يتوقف برسالة تطلب فحص الفيديو وإضافة مهمة جديدة. لا يختار لغة بديلة بصمت. تمنع بصمة الاختيار وبيان البث استخدام أجزاء محفوظة مع اختيار مختلف، وتستمر المهام القديمة بالاختيار الافتراضي.

الملفات المباشرة مثل MP4 تُنقل بصيغتها الأصلية. يمكن استخراج الصوت من روابط الوسائط المدعومة باختيار MP3 أو M4A، وتختفي دقة الفيديو عند اختيار الصوت. يُفضّل مسار صوت منفصل دون تنزيل مقاطع الفيديو. إذا لم يتوفر إلا ملف مدمج، يوضح الوصف أن تنزيله ضروري لاستخراج الصوت. لا تُضاف ترميزات أو لغات لا يعلنها المصدر، ولا يُجمع أكثر من مسار صوتي. معدل البت المستهدف لا يرفع جودة المصدر؛ قد يختلف الحجم النهائي عن حجم النقل. يفحص المحرك صيغة الصوت وترميزه ومدته وغياب الفيديو قبل اعتماد الملف. تستمر حدود YouTube العام وHLS/DASH المسجل غير المشفر؛ لا تدعم هذه النسخة DRM أو البث المباشر أو نقل جلسة دخول YouTube. قد تتغير إتاحة الصيغ من موقع إلى آخر.

تعتمد صياغة أوامر الاختيار والدمج على [وثائق yt-dlp الرسمية](https://github.com/yt-dlp/yt-dlp#format-selection)، مع أدوات مثبتة الإصدارات والبصمات في `media-runtime.lock.json`. لا تُقبل أوامر أدوات أو محددات صيغ حرة من صفحة الويب؛ تُرسل معرفات صوت مقيدة، ويعيد المحرك حلها من الفحص الفعلي.

للمطورين: تفحص `test/media-formats-real.test.mjs` حاويات فعلية وترميزات الصوت والصورة وتوقيت بدايتهما ومسارين صوتيين بترددين مختلفين، مع الإيقاف والاستئناف بعد إعادة إنشاء الخدمة. يشغّل `npm run test:media-browsers -- --case=audio` Chrome وEdge بملفات تعريف اختبارية، ويفحص `npm run smoke:media-options` واجهة التطبيق. تظل اختبارات التثبيت والترقية والإزالة داخل VM مؤجلة بطلب المستخدم.

يستخدم استخراج الصوت [خيارات المعالجة الرسمية في yt-dlp](https://github.com/yt-dlp/yt-dlp#post-processing-options). يشغّل `npm test` الاختبارات داخل مجلد مؤقت واحد، ثم يحذفه عند النجاح أو الفشل، دون حذف الشيفرة أو ملفات المستخدم.
