# بنية سَهم

| المجلد | المسؤولية |
|---|---|
| src | محرك التنزيل وحالة المهام والتقسيم والاستئناف وFTP والشبكة والوكلاء والحصص والجدولة ونسخ المواقع والوسائط. |
| electron | دورة حياة Windows ونافذة التطبيق وIPC وpreload ومراقبة الحافظة ونوافذ المواقع المعزولة. |
| ui | واجهة عربية RTL دون إطار واجهة خارجي. |
| browser | إضافة Manifest V3 ومضيف الرسائل المحلية وبروتوكول الاتصال. |
| scripts | تجهيز الأدوات والبناء والتحقق من الحزم واختبارات التكامل. |
| test | اختبارات المحرك والبروتوكولات وحالات الفشل بالخوادم والتجهيزات المعزولة. |

تُدار إعدادات الاتصال في مسار مشترك. ينفذ Windows SSPI المصادقة الأصلية عند ضبطها؛ لا يحاول JavaScript تنفيذ Kerberos. تستخدم نافذة المواقع المحمية اعتراض Fetch عبر CDP لتوجيه طلبات الأصل المضبوط إلى هذا المسار، مع بقاء سياسة Cookie وCORS تحت إدارة Chromium.

تستعمل الوسائط أدوات yt-dlp وFFmpeg وDeno في عمليات خارجية دون shell. تحدد قائمة الأدوات المقفلة ما يجوز إدخاله إلى الحزمة. لا يسمح تجهيز الأدوات بإصدار متحرك أو اختلاف بصمة، ويتحقق من الرخص أيضًا.

توجد ثلاثة أنواع من الدليل: اختبار وحدات وخادم محلي، واختبار نافذة Electron أو متصفح معزول، ثم فحص الحزمة الموزعة. تُسجل الإصدارات والملفات والبصمات مع النتائج. لا يثبت نجاح نوع واحد كل الأنواع الأخرى.
